# AI Warranty Intake

Одностраничная презентация учебного проекта AI Warranty Intake.

## Запуск локально
Откройте `index.html` в браузере. Сборка и установка зависимостей не требуются.

## Публикация на Cloudflare Pages
1. Откройте Cloudflare Dashboard → Workers & Pages → Create → Pages.
2. Выберите подключение к Git и репозиторий `sk8teJ/AI-Warranty-Intake`.
3. Production branch: `main`.
4. Build command оставьте пустой.
5. Build output directory: `.` (корень репозитория).
6. Нажмите Deploy.

## Содержимое
- `index.html` — адаптивная презентационная страница со стилями и интерактивностью внутри одного файла.

## Особенности
- Адаптивная вёрстка для мобильных, планшетов и десктопов.
- Анимированное появление секций и индикатор прокрутки.
- Интерактивные вкладки этапов обработки заявки.
- Раскрывающиеся FAQ.
- Мобильное навигационное меню.
- Учитывается системная настройка reduced motion.

Учебный MVP: AI помогает с первичной обработкой документов, но не принимает окончательное решение по гарантийному обращению.
